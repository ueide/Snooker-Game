# Snooker-Game
I developed this entire project from scratch. All the ideas, design, user interface, playable functions, and code were created and produced by me. I used the Matter.js, P5.js documentation to learn how to use the libraries.
For code based on a tutorial or website reference, you will find a comment quote next to it. If there is no reference, it's because I didn't use it.

I referenced this to determine the position of the balls.
Ball position from up view:
Black - ~32.2cm from the right cushion.
Pink – ~ 89cm from the right cushion.
Blue – middle of the table
Yellow, Green and brown – D area
Reds – the axis of the pyramid is close to the pink.
